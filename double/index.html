你常去的地方，有一堆「替身」：路上花的时间一模一样，你却一个都没去过。 地图只回答「到那儿要多久」，从不回答「同样的时间还能到哪儿」。

它在替你做哪个决定

周末想换个地方，但不想多花路上时间。你打开地图，它只会回答「到某处要多久」—— 于是你只能回到那几个已经去过的地方。这个页面反过来问：同样的时间，还能到哪儿？

–

    数据说明：8 座城市 × 3 类出发点（居住 / 办公 / 老城）× 每城 60–64 个真实 POI（公园 / 博物馆 / 商场 / 书店 / 体育馆 / 电影院 / 展览馆 / 景点）， 共 – 组真实驾车耗时，全部来自腾讯地图 WebService 距离矩阵（driving）， 采集于 2026-10-19，为典型路况下的测算值，非实时路况。
    口径：替身 = 与锚点耗时差 ≤ 2 分钟且类别不同的去处；厚度 = 同一等时带内最远 / 最近的直线距离之比； 可达玫瑰只统计样本数 ≥ 2 的方位（只有 1 个点的方位由单点决定，会产生几十倍的假比值）。
    反例：杭州·临平（远郊居住区）在 20 分钟档内替身为 0 —— 住在那儿，20 分钟确实哪儿也去不了。这不是 bug，是结论。
