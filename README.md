# 图个好玩 · 大地图参赛作品集

九件围绕「地图不只是看图，而是回答一个具体问题」的交互作品。全部纯前端、零后端，
地图能力来自腾讯位置服务 JavaScript API GL。

在线访问（GitHub Pages）：https://wangziji.github.io/tugehaowan-maps/

| 作品 | 它回答的问题 |
| --- | --- |
| [对跖点](./antipode/) | 从脚下打一条洞穿过地球，对面是谁 |
| [静坐时速](./stillspeed/) | 你坐着不动，其实正以多快的速度在动 |
| [人生质心](./centroid/) | 你去过的地方，重心落在哪儿 |
| [祖先洪流](./ancestors/) | 你的姓氏，一千年前从哪里流过来 |
| [地球鼓包](./bulge/) | 地球不是球，鼓出来多少 |
| [还剩几回](./ntimes/) | 你这辈子还能去几次那个地方 |
| [失联半径](./lostradius/) | 你以为你拥有这座城市，其实只拥有几平方公里 |
| [停转](./stopspin/) | 地球突然不转了，会发生什么 |
| [去趴活儿](./pahuo/) | 在哪儿等单最划算 |

每一件都配了数学断言脚本（`verify.js`）与真实浏览器验收脚本（`browser-check.js`），
结论数字来自脚本输出而不是估计。

注：托管在 GitHub Pages 的这份是公网镜像；腾讯内网另有同名站点。
