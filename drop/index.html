落点 · THE DROP

把你送到哪儿，比送多远更值钱。

计价器只算你在车上的那段时间。可司机送完你，还得空着车开到下一单去 —— 那段时间没人付钱。 把「送到那儿之后要空驶多久」算进分母，同一张计价器上的两单，真实时薪能差两倍多。 这个差值只由一件事决定：你让他把你放下车的那个地方。

结论

—
演示数据 / 估算说明。车费按各城市公开出租车计价规则的简化模型估算（起步价 + 里程费 + 时长费），不是实际账单； 「区域需求强度」用每个点周边 1 km 内的地点检索数量（公司 + 美食）作代理，不是真实订单量； 城市被离散成 16 个采样点，真实路网远比它密。本作品给的是可横比的相对量，不是司机的真实收入。
数据：腾讯位置服务 —— 距离矩阵（驾车，实测 6×16×16 段）、地点检索（周边 1 km 计数）、逆地理（区域命名）。运行时零网络请求，全部数据已预生成打包。
方法：区域需求强度 w → 下一单起点分布 = 需求权重 × 距离衰减核 exp(−d/3km) → 落点 j 的期望空驶时长 A(j) = Σ P(i|j) · 路网耗时(j→i)。真实时薪 = 车费 ÷ (载客时长 + 期望空驶时长)。同区单按 900 米 / 3 分钟计入，否则热点区会算出 0 分钟这种荒谬值。
已知边界：上海、深圳这类单中心城市里，「那儿有多少需求」和「离市中心多远」高度共线，无法区分谁在起作用 —— 页面只给数字，不替它们下结论。
